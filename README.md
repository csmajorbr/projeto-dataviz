# Projeto Dataviz

Estudo do projeto de visualização de dados do livro *Python Crash Course* (3ª edição, capítulos 15 a 17).

## Objetivo
Praticar Python aplicado a dados: gráficos com Matplotlib e Plotly, leitura de CSV e JSON e uso de APIs.

## Como rodar
1. Crie o ambiente: `conda env create -f environment.yml`
2. Ative: `conda activate estudos-dados`
